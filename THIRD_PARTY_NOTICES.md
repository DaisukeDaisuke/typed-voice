The production binary known-word index is generated on the GitHub Actions CPU runner from `VOICEVOX/kanalizer-dataset` revision `21fc9ccf25d3b18030d3e0db3bf5994229fae697` (`v3`), which is also distributed under the MIT License. This is the dataset revision used to train Kanalizer model v5. `VOICEVOX/kanalizer-model` v5 is also distributed under the MIT License, Copyright (c) 2025 VOICEVOX. The Kanalizer model itself is not redistributed with this repository or embedded in the WASM; during the online setup for offline voice use, the browser obtains the upstream `VOICEVOX/kanalizer-model` v5 model directly from Hugging Face, verifies the LFS SHA-256 reported by the unauthenticated Hugging Face model API, and stores the verified model in a Service Worker-preserved Cache Storage entry for later offline use. Rust dependency notices for the browser WASM are regenerated from the pinned submodule plus `patches/kanalizer-browser.patch`, with the same `external_model` feature and `wasm32-unknown-unknown` target, by `npm run licenses:kanalizer`.
